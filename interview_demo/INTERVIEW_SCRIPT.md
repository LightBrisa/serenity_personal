# Serenity Personal 3 分钟演示话术

## 0:00–0:35｜先说产品任务

Serenity 不是帮人自动炒股，而是把“听来的观点”和后续变化拆成可核对的判断材料。人负责做决定，系统负责把来源事实、可能冲突和未知项准备清楚。

## 0:35–1:15｜先保留变化前的判断

页面先展示变化发生前的 NVDA 判断。这样新材料不会直接覆盖旧观点，也不会让系统从后来结果倒推我当时怎么想。

## 1:15–2:05｜来源与推断分层

Form 8-K 卡片只保存来源中的事实：H20 出口需要许可，以及公司预计相关费用最高约 55 亿美元。下面的三栏才是影响整理：它可能削弱哪些前提、为什么、还缺什么才能判断。离线包使用预置回归样例，页面有明确标识；在线项目则由服务端 Responses API 生成同一数据合同，并二次校验 assumption ID。

## 2:05–2:45｜由人做决定

我选择 KEEP、WATCH、GATHER 或 INVALIDATE，再写理由。模型没有权限输出或写入这个选择；`ThesisState` 只由确定性状态机根据人的操作更新。

## 2:45–3:00｜讲清边界

这个 ZIP 保证无安装、无账号、无网络可重复演示。它证明产品闭环与数据边界，不冒充实时模型调用。真实模型是否已跑通，单独看验证报告里的 `liveModelSmoke`。
